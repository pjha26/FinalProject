# Presentation audit and fixes - 29 October 2026

This repository estimates relative depth from RGB and saves visualizations, numerical maps and evaluation evidence. This audit assumes one person running the Windows presentation on the prepared RTX 4050 laptop. It prioritizes demo startup, model/input boundaries, scoring and preservation of existing outputs.

## Fixed findings

1. **Fresh CARLA launch fails before startup** (`tools/present.py`). The server log was opened under `runs` before that directory was created. A fresh asset-only checkout could raise `FileNotFoundError`. The launcher now creates the parent directory. A new regression test starts from a temporary checkout without `runs`, verifies creation of the server log and checks cleanup of the owned process.

2. **Port timeout incorrectly permits a second server launch** (`tools/present.py`). A TCP timeout was treated like connection refusal, although it does not establish that the port is free. The launcher now stops with a useful error on timeout. A new regression test verifies that no process is spawned in that case. Connection refusal still permits startup, and a connected port still blocks it.

3. **Still-image fallback command is invalid** (`docs/presentation_runbook.md`). The runbook used `project.py image`, which the parser does not support. It now uses `project.py infer`. The corrected command was executed with CUDA and point-cloud export; it saved the preview, numerical maps and a 10,000-point relative cloud.

## Local setup repaired

The prepared `FinalProjectDemo` folder lacked the five-frame diagnostic reference package required by the full delivery validator. The existing `project.py prepare-reference-eval` command downloaded and checksum-verified the pinned package and created its manifest. No KITTI download or model training was needed.
